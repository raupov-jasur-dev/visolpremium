# VisolPremium

> Premium digital invitation and greeting card platform.

VisolPremium — foydalanuvchilarga zamonaviy raqamli **taklifnoma, tabriknoma va video-tabriklar** yaratish imkonini beruvchi web platforma.

🔗 **Live Demo:** https://visolpremium.vercel.app

---

## ✨ Features

* 💌 Digital invitation creation
* 🎉 Greeting card creation
* 🎨 Multiple premium templates
* 🖼️ Custom images and galleries
* 🎵 Background music
* 📍 Location and map support
* 📱 Fully responsive design
* 🔐 Authentication
* 💾 Invitation saving and management
* 💬 RSVP functionality
* 🎬 Video invitation templates

## 🔐 Environment Variables

For production deployment, configure the required environment variables such as:

```env
DATABASE_URL=
BETTER_AUTH_SECRET=
GROK_AUTH_CLIENT_ID=
GROK_AUTH_CLIENT_SECRET=
```

> Never commit real secrets or `.env` files to the repository.
